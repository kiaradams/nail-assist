
# Nail Assist Website

## Project Description

Nail Assist is a nail care and beauty website that provides
information about professional nail services and treatments.

The website allows visitors to explore services, view prices,
search for services and submit enquiries or general messages.

## Website Pages

- Home
- Services
- About Us
- Contact
- Enquiry

## Services and Prices

| Service | Price |
|---|---:|
| Manicure | R180 |
| Pedicure | R250 |
| Nail Art | R150 |
| Gel Nails | R300 |
| Acrylic Nails | R350 |
| Nail Repair | R80 per nail |
